What has been verified, and how

npm run test:fork forks live Coston2, deploys the facilitator onto the fork, and settles a real invoice against the real FXRP contract - the deployed vendored FAsset, resolved through AssetManagerFXRP.fAsset(), not a mock. Each property below is asserted, and the attacks are run as attacks.

  • The payment is gasless. The payer's native balance is forced to zero before signing and checked to still be zero after. The receipt shows the relayer's address paid.
  • Signatures verify against FXRP's vendored permit - not stock OpenZeppelin, and not a mock.
  • A relayer cannot redirect the payment. A third account calls settle() substituting itself as payee and is rejected with IntentNotSignedByPayer.
  • An invoice settles once. Replaying the same signatures reverts with AlreadySettled.
  • A front-runner cannot grief a payment. A third account submits the permit straight to FXRP, burning the nonce. settle() still delivers in full.

Where the fork test stops short.

The token is real, but the payer's FXRP balance is synthetic - written straight into the token's balance mapping on the fork, because minting FAssets legitimately requires an XRP payment proof that a test cannot produce. So the fork run proves the contract logic and the signing path; it does not prove a payer funded through the normal FAssets route.

What is not done

A gasless settlement on live Coston2. settle.ts is written and has been run against the deployed facilitator on a fork, but not yet on the live chain. That needs a payer wallet holding real FXRP and deliberately zero C2FLR - and that zero is the whole demonstration, so it is worth doing properly rather than approximating.

FTSO pricing. Invoices are denominated in FXRP today. Quoting in USD and converting at Flare's onchain feed is the next piece, and it is what makes the oracle load-bearing rather than decorative.

The x402 service and the MCP server. Neither exists yet. The home page describes the flow they will expose; it does not claim they run.

Roadmap

  1. Land a live gasless settlement

    A payer with FXRP and zero C2FLR pays an invoice on Coston2, with the transaction hash published here.

  2. Price invoices in USD via FTSO

    Read the feed onchain, convert at settlement time, and quote the 402 in dollars.

  3. Ship the facilitator service and middleware

    So any Flare service can charge for a request in about five lines of Express.

  4. An MCP server

    So an assistant can pay for what it uses without a human in the loop.
